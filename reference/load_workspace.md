# Load a 'JDemetra+' workspace

Function to load a 'JDemetra+' workspace.

## Usage

``` r
load_workspace(file)
```

## Arguments

- file:

  the path to the 'JDemetra+' workspace to load. By default a dialog box
  opens.

## Value

An object of class `"workspace"`.
